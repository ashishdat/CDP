# config/output_specs/ub92

One YAML file per UB92 record type (01, 10, 20, 30, 31, 40, 46, 60, 70, 80,
90, 95, 99 — the record types observed in the supplied Group C reference
output), same field schema as `config/output_specs/nsf`, transcribed from
`UB92 File Specs - February 2012.doc`. Populated in Phase 3.
