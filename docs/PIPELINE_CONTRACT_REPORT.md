# Geometry ? OCR Pipeline Contract Report

Finding before fix: **PIPELINE_CONTRACT_FAILURE**.

`app.process_one()` generated GeometryResult successfully, but its
`geometry_telemetry.json` omitted three inputs required by
`scripts.ocr_from_geometry.run()`: registration_evidence, source, document_id.
The first access failed with `KeyError: registration_evidence`. Adding only
that key would have exposed the other two omissions next.

The earlier successful manually enriched artifact did not prove that the
application producer satisfied this contract. The new test uses the actual
producer output without enrichment.

## Change

Two added payload lines in app.py copy the three missing fields from the same
execution state. The existing JSON object, file names, and all existing keys
are preserved. No new telemetry schema, wrapper, fallback, algorithm, or
provider is introduced. OCR resume remains unchanged.
