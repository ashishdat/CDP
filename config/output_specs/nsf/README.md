# config/output_specs/nsf

One YAML file per NSF record type (AA0, BA0, BA1, CA0, DA0, DA2, EA0, EK0,
FA0, HA0, XA0, YA0, ZA0 — the record types observed in the supplied Group
A/B/D reference outputs), each field described by
`record_type/field_name/start_position/length/alignment/padding_character/
data_type/format/required/default/source_field`, transcribed from
`NSF Matrix Version 2 15 - June 2013.doc` (see docs/DATASET_FINDINGS.md).
Populated in Phase 3.
